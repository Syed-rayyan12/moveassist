MOVEASSIST — HTML / CSS / JAVASCRIPT FRONTEND

Files:
- index.html
- all inner page HTML files
- style.css
- script.js

How to use:
1. Upload the whole folder to hosting.
2. Open index.html, or configure your server to use index.html as the homepage.
3. No Node.js, React, Next.js or build step is required.

The website follows the supplied MoveAssist brief and screenshot direction:
dark premium header/hero, white sections, lime green accent, service cards,
StoreAssist feature, process, CTA, trust, Instagram/blog/FAQ, footer,
responsive layouts and frontend form states.

Important:
- Forms are frontend/demo only and show a success state. Connect them to the client's
  email/CRM endpoint before launch.
- Legal pages are editable placeholders and must be replaced with approved final wording.
- Reviews, stats, certifications and partnerships are not fabricated.
- Images currently use remote image URLs so the folder remains lightweight.
